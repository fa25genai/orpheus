What is a programming language? • Programming languages allow us to give instructions to a computer • Many different human languages → many computer programming languages • Code cannot be directly understood by a computer: it must first be translated into a lower language that the computer can execute, called a binary • Translating code into binary is called compiling or compilation • Every language, from C to Python to Java, has its own distinct features, as well as commonalities with other languages

Advantages of compiled & interpreted languages
• Advantages of compiled languages
• Faster performance due to translation to machine code in advance
• Opportunity to apply quite powerful optimizations during the compile stage
• Advantages of interpreted languages
• Easier to implement (writing good compilers is very hard)
• No need to run a compilation stage: can execute code directly on-the-fly
• Better suited for dynamic languages due to on-the-fly code changes and immediate feedback
