JSON: JavaScript Object Notation
Open standard format
Uses human readable text to transmit objects consisting of key value pairs
Language independent data format
Structure of JSON: https://www.json.org/json-en.html
Try it out: https://jsoneditoronline.org/
Example
Movie
- imdbID: String
- title: String
- simplePlot: String
- genres: [String]
- year: int
- rating: String
hiddenFigures: Movie

title = "Hidden Figures"

genres = ["History", "Drama"]
year = 2016
rating = "7.8"
