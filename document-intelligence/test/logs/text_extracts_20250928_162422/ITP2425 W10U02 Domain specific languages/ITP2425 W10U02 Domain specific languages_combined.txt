Domain Specific Language (DSL) • Specialized in a particular application domain • In contrast to general purpose languages (GPL), e.g. Java, which are broadly applicable across domains • There is a wide variety of DSLs for common domains, such as HTML for web pages • The line between GPLs and DSLs is not always sharp • A language may have specialized features for a particular domain but be applicable more broadly • Conversely, it may in principle be capable of broad application but in practice used primarily for a specific domain © 2024 Stephan Krusche Introduction to Programming - W10 Programming Languages 16

SLIDE 3
--------------------
Advantages and disadvantages of DSLs
+ Efficiency
+ Integration between developers and application domain experts
+ Independent of the target platform
+ Increased quality
- Narrows the use
- Learning curve
- Additional effort for configuration
- DSL creators need domain knowledge as well as language-development knowledge

import org.json.*;
import java.util.*;
public class Movie {
// ...
// Deserialize: JSON -> Movie
public Movie(JSONObject jsonObject) {
imdbID = jsonObject.getString("imdbID");
title = jsonObject.getString("title");
simplePlot = jsonObject.getString("simplePlot");
JSONArray genreJsonArray = jsonObject.getJSONArray("genres");
genres = new String[genreJsonArray.length()];
for (int i = 0; i < genreJsonArray.length(); i++) {
genres[i] = genreJsonArray.getString(i);
}
year = jsonObject.getInt("year");
rating = jsonObject.getString("rating");
}
JSON can be seen as a mixture of maps (JSONObject) and arrays (JSONArray)
