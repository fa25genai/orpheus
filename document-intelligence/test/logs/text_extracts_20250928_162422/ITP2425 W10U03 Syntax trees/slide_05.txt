Syntax tree
• Tree representation of the syntactic structure of text (often source code) written in a formal language
• Each node of the tree denotes a construct in the text
• The syntax is abstract: it does not represent every detail, but just the structural or content-related details
• For example: grouping parentheses are implicit in the tree structure, so these do not have to be represented as separate nodes
• A syntactic construct like if-else statement may be denoted by means of a single node with e.g. three branches
• Used in compilers, program analysis and program transformation systems
