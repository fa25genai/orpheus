SLIDE 12

Advantages of compiled & interpreted languages
• Advantages of compiled languages
• Faster performance due to translation to machine code in advance
• Opportunity to apply quite powerful optimizations during the compile stage
• Advantages of interpreted languages
• Easier to implement (writing good compilers is very hard)
• No need to run a compilation stage: can execute code directly on-the-fly
• Better suited for dynamic languages due to on-the-fly code changes and immediate feedback
